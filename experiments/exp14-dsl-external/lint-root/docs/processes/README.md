# Generated process documents

> Generated by `tools/docgen.sh` (`tools/diagram-gen`'s `docgen` binary) — **do not hand-edit**; regenerate after any model change.

One human-readable document per process, boundary function and composite flow, generated from each model crate's source (candidate R20): the signature is the work-instruction skeleton, the `VALUE`/const parameters supply the numbers, `Placeholder:` tags are the open-items list, the requirement bounds with their `Verifies:` tags are the compliance matrix, and the R9 connection graph states where each process fits as **needs / feeds** — a dependency graph, not a fixed procedure. Where the extraction cannot see something, the document says so (HTML comment) rather than guessing.
